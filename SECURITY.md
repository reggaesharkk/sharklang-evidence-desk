# Security and scope

SharkLang Evidence Desk is a local evaluation prototype. It does not execute the archive it inspects and is not a production security control. Its checks are bounded and heuristic; a PASS is not a security certification.

Please report suspected vulnerabilities to [starxshark@gmail.com](mailto:starxshark@gmail.com). Do not send API keys, private keys, or unredacted archives in a report. I cannot promise a response time or security-support SLA.
