WHAT IT DOES

A pre-review check, not a security verdict.

The app reads the archive in place. It can flag unsafe paths, duplicate or case-colliding names, encrypted entries, manifest mismatches, unlisted files, and selected secret-like patterns. A report can be saved locally as JSON.

I keep test execution and mathematical proof checking marked OPEN. Matching hashes establish that bytes match a manifest; they do not show that code is safe, tests passed, or a theorem is correct.

CURRENT BOUNDARY

What it does not do

  • It does not extract or execute archive contents.
  • It does not run a test suite or compile Lean proofs.
  • It cannot guarantee that secrets are absent.
  • It is not a production security service.

OPTIONAL · REAL PROVIDER REQUEST

Plain-language explanation with Gemini

The local audit works without an API key. If enabled, the app sends only aggregate counts and status labels to Gemini through the bundled SharkLang request flow. It does not send the archive, file names, file contents, or detected secret values. Provider usage may be billable.
